Git マッチング

Gitの用語と基本コマンド110問を、カードをタップしたりスワイプしたりしながら学習するiOSアプリです。

よくある質問

カードの答えを確認するには？

カードをタップすると、用語の説明やコマンドが表示されます。確認後は左右のスワイプまたは画面上のボタンで「覚えた」「覚えてない」を記録できます。上方向へのスワイプではお気に入りに登録できます。

どのような内容を学べますか？

Git用語23問とGitコマンド87問を収録しています。Gitの基本用語、開始・取得・状態確認、ステージとコミット、差分と履歴、ブランチ操作、マージ・リベース・競合、リモートとの共有、取り消し・復元、一時退避・タグ、設定・調査・保守の10カテゴリに分かれています。

出題方法を変更できますか？

設定画面で、出題する分野（Git用語・Gitコマンド）、お気に入りのみの出題、ランダム出題、逆向きの出題（答え → 問題）、設定回数覚えた問題を出題しない機能を選択できます。出題終了までの回数は1回から10回まで設定できます。

カードにメモを残せますか？

学習中のカード右上のボタンから、覚え方のコツや使う場面などを自由にメモできます。メモは設定画面の「メモ」から一覧で確認・検索できます。

復習の通知を受け取るには？

設定画面の「復習時間を通知」をオンにし、通知時間を選ぶと、毎日その時間に端末から復習のお知らせが届きます。届かない場合は、iPhoneの「設定」でこのアプリの通知が許可されているかご確認ください。

学習履歴はどこに保存されますか？

学習状態、覚えた回数、お気に入り、周回数、メモ、出題方法、表示テーマ、通知設定などは端末内に保存されます。運営者のサーバーへの送信や、端末間の同期は行いません。

学習履歴を削除するには？

アプリの「設定」→「学習履歴をリセット」を使用してください。覚えた回数、学習状態、お気に入り、周回数が削除されます。分野・出題方法・表示テーマの設定と自分のメモは残ります。累計の学習回数と、広告・メッセージの表示到達状況はリセットされません。メモは各カードのメモ画面から個別に削除できます。

コマンドが手元の環境で動作しません

Gitのバージョン、OS、シェル、Gitの設定、ホスティングサービスなどによって、利用できるオプションや動作が異なる場合があります。Git公式ドキュメントもあわせてご確認ください。掲載内容の誤りを見つけた場合はお問い合わせください。

広告に関する設定を変更するには？

広告に関する同意の変更が必要な場合に限り、設定画面に「プライバシーとCookieの設定」が表示されます。表示されない場合、アプリ内で変更が必要な同意設定はありません。
